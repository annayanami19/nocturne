## 🔭 Tentang

**Nocturne** adalah ekstensi browser (Chrome/Edge/Brave) yang mengubah tampilan halaman web menjadi dark mode secara instan — tanpa perlu dukungan dark mode dari situsnya.

Cukup satu klik, halaman terang yang silau langsung berubah menjadi gelap dan nyaman dibaca, sementara gambar, video, dan emoji tetap tampil normal. Semua setelan tersimpan otomatis dan bisa disesuaikan per situs.

## ✨ Fitur

- 🌙 **Smart Invert** — halaman gelap instan, gambar/video/emoji tetap natural
- ⚡ **Toggle Global & Per-Situs** — kendali penuh untuk semua situs atau satu domain saja
- 🚫 **Daftar Pengecualian** — situs tertentu tidak pernah digelapkan
- 🎚️ **Slider Brightness / Contrast / Warmth** — sesuaikan kenyamanan mata secara real-time
- ⌨️ **Shortcut `Alt+Shift+D`** — toggle cepat dari keyboard
- 🔄 **Live Sync** — perubahan setelan langsung berlaku di semua tab tanpa reload
- ☁️ **Sinkronisasi** — setelan ikut profil browser antar perangkat
